# גוגל + הפאנל של ניק

אתר שנראה בדיוק כמו דף הבית של Google. מי שמחפש **ניק** מקבל פאנל סודי: מעלים סאונד, לוחצים „נגן לכולם", והסאונד מתנגן חזק אצל כל מי שנמצא באתר.

## הפעלה במחשב
לחיצה כפולה על `start.bat`. השרת עולה והאתר נפתח בדפדפן (http://localhost:3000).
לא צריך להתקין כלום, רק Python (כבר מותקן).

- **חברים באותו Wi-Fi:** החלון של השרת מציג כתובת `Network: http://192.168.x.x:3000`. שולחים להם אותה.
  בהפעלה הראשונה Windows ישאל אם לאפשר ל-Python גישה לרשת. מאשרים ל„רשתות פרטיות".
- החלון חייב להישאר פתוח כל עוד רוצים שהאתר יעבוד.

## להעלות לאינטרנט (חינם) עם Render
1. מעלים את התיקייה הזו לריפו ב-GitHub.
2. ב-render.com: New → Blueprint → בוחרים את הריפו. הקובץ `render.yaml` כבר מגדיר הכל.
3. מקבלים כתובת `https://….onrender.com` ושולחים לחברים.

בחבילה החינמית האתר „נרדם" אחרי 15 דקות בלי מבקרים (הכניסה הבאה לוקחת כחצי דקה), וסאונדים שהועלו נמחקים כשהשרת מופעל מחדש.

## חשוב לדעת
- דפדפנים חוסמים צליל עד שהמבקר לוחץ/מקליד בדף פעם אחת. אם סאונד נשלח לפני כן, הוא מתנגן ברגע שהמבקר לוחץ או מקליד (עד 30 שניות אחרי השליחה).
- „ממש חזק" = עד 500% הגברה דיגיטלית בתוך הדפדפן. אי אפשר לעקוף את עוצמת הרמקול של המכשיר עצמו.
- חיפוש רגיל נשאר בתוך האתר: דף תוצאות שנראה כמו Google, עם החשבון של נועה ותיבת חיפוש שבה **ניק** עדיין פותח את הפאנל. התוצאות מגיעות מוויקיפדיה, כי Google הפסיקה לתת את התוצאות שלה לאתרים חיצוניים. לחיצה על תוצאה פותחת אותה בלשונית חדשה, כך שהאתר נשאר פתוח ברקע וממשיך לשמוע.
- הסאונדים נשמרים בתיקייה `data/`.
